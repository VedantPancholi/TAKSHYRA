# Contributing to Takshyra

Start with `README.md`, `docs/00_INDEX.md`, and `docs/24_ROADMAP.md`. Work within a selected milestone and preserve unrelated work. PRs should state the problem, requirement IDs, design tradeoffs, security and tenant impact, migrations, exact test commands and outcomes, limitations, and documentation updates. Implement working vertical slices with server-side tenant checks, typed input validation, durable state, bounded retries, and tests for unauthorized access. Do not add arbitrary shell, SQL, Python, Terraform or cloud operations to application actions. Do not commit credentials, customer data, unsupported Azure operations, or CI checks that silently skip required tests. Treat planned specifications as planned until real behavior is verified.
