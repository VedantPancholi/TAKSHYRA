# Contributing to Takshyra

Start with `AGENTS.md` and `CODEX_START_HERE.md`. Work within a selected milestone. PRs should state: problem, requirement ID(s), design tradeoffs, security/tenant impact, migrations, tests with exact commands, screenshots if UI, limitations and doc updates. Do not add unsupported Azure resource operations, silent 'passing' placeholder CI checks, or raw personal/customer data. Treat the blueprint as planned specification until real app code exists.
