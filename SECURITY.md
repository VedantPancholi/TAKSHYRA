# Security policy (blueprint stage)

Takshyra Core has a development-only M1 implementation and is **not production security reviewed**. Do not connect it to production resources or real customer data. See `docs/17_SECURITY_AND_THREAT_MODEL.md` for expected controls and `docs/IMPLEMENTATION_STATUS.md` for verified gaps. Report vulnerabilities privately through repository security advisories or the maintainer's designated contact once published; never attach exposed secrets to public issues. Do not assert the system is certified for any regulatory framework.
