# ADR 0005 — Evidence provenance outranks AI claims
**Status:** Accepted as initial design (2026-10-09)

**Decision:** Agent hypotheses cite persisted evidence, distinguishing verified causal checks from correlation and assumptions. Memory stores verified incidents separately from unresolved hypotheses. Model confidence is categorical unless calibrated.

**Tradeoffs:** More structured records but better trust and measurable diagnosis quality. UNKNOWN is valid output.
