# Codex M6 — usable operations console

Build Next.js/TypeScript web with accessible components and typed API client: demo sign-in, Overview, Pipelines/Runs, Contracts, Data Assets/Lineage, Incident Center, Incident detail with evidence/hypotheses, Proposal Approval Queue, Audit. Implement responsive tables, filters/pagination, readable dates and clear empty/loading/error cases. Model demo vs actual sources visibly.

Require RBAC server-side on all mutations; UI hiding buttons alone is not security. Show separate execution/quality/publication statuses and proposal exact payload/expiry/risk; never show secret material.

**E2E:** viewer cannot run or approve; approver can act only within membership; simulated data clearly labeled; role changes invalidate action; an engineer can trigger seeded failure and inspect linked incident and approved retry end to end via UI. Run typecheck, lint, build and e2e tests.

**Exit:** an uninterrupted user journey exists through UI; no stubbed fake metrics on normal pages.
